# 修改流程（独立路径）

## 适用

本技能已有内容需要纠正或加严时（不改被测对象本身）。

## 步骤

1. [初始化/](../初始化/初始化.md)（同创建路径前置六项）；
2. **定位**：grep 目标文件，确认属 `branch/`、`references/` 还是 `resistance/`；
3. **镜像**：变更一律先落 tmp 镜像目录，不在本体直接编辑；
4. **审批**：红线区与 `resistance/` 变更先记逻辑链＋双链辩论，再走
   [../../update/update.md](../../update/update.md) compare → release → clean；
5. **复验**：`check_links.py`／`check_len.py`／`lint_deps.py` 三项全绿
   （校验脚本在 `scripts/`，本体目录内运行）；
6. **记账**：`CHANGELOG.md` 增条目，`process_chain.py save --step 修改流程`。

## 判据变更须同步

改动分层策略、门禁阻塞项、分诊三分法口径时，必须同步
[测试策略/](../测试策略/测试策略.md) ·
[用例设计/](../用例设计/用例设计.md) ·
[失败分诊/](../失败分诊/失败分诊.md) ·
[质量门禁/](../质量门禁/质量门禁.md) 与对应约束，不得只改一处。

## 禁止

- 放宽或删除既有约束（只可加严）；
- 未经 compare 直接 release（静默写盘）；
- 顺手改动其他技能目录。

## 退出

标记「完成项目修改」，收口返回调度方。
