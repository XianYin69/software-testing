# 初始化（两条路径共同前置）

## 子节点

1. **建立工作空间**：确认被测对象根目录、测试代码目录、报告输出目录；
   未指定时按 [沙盒机制](../../resistance/沙盒机制/沙盒机制.md) 固定路径建沙盒。
2. **加入 MIT 协议**：写 `LICENSE`（已有不覆盖）。
3. **建立计划任务目录**：`planned_tasks/README.md` ＋ `template.json`
   （已有不覆盖；到期由 SMS 调度器执行，技能自身不执行）。
4. **依赖自检**：`python ../../scripts/deps_check.py` 校验 `dependence/deps.json`
   每条含 `source_url`（本地技能 `local://<skill-id>`）。
5. **git 就位**：无 `.git` 即 `git init`；受权限门限时如实记录受阻并跳过
   （见 [git工作流约束](../../resistance/git工作流约束/git工作流约束.md)）。
6. **挂载机制**：逻辑链/过程链/惩罚/压缩/回收五机制，
   见 [逻辑链机制](../../resistance/逻辑链机制/逻辑链机制.md)。

## 退出条件

六项全绿并 `process_chain.py save --step 初始化`；缺任一项不得进
[需求确认/](../需求确认/需求确认.md)。

## 反例（禁止）

- 未确认被测版本与运行环境就试跑测试命令；
- 把 `.venv/`、`htmlcov/`、`test-results/` 写进本 skill 目录；
- 跳过 MIT／计划任务直接开写用例。
