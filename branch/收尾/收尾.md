# 收尾

## 步骤

1. **交付物归位**：测试资产（用例、脚本、夹具）、运行记录与门禁结论按目标项目
   约定就位；临时产物只留在 tmp 镜像；
2. **门禁结论交付**：把 [质量门禁/](../质量门禁/质量门禁.md) 的放行判据结论交给
   发布侧（packaging-and-release），本技能不执行发布动作；
3. **沉淀**：新经验回写 [知识库构建/](../知识库构建/知识库构建.md) 产出目录；
4. **提示词与骨架同步**：`SKILL.md` 与 `agent/` 四格式提示词保持一致
   （一句话：使用 `software-testing` skill 来完成用户请求）；
5. **自更新释放**：镜像变更 compare → release → clean
   （见 [update.md](../../update/update.md)），不加 `--yes` 只预览；
6. **垃圾回收**：`python ../../scripts/garbage_collect.py --path <镜像>` 预览后删除；
7. **记账**：`CHANGELOG.md` 增条目，`process_chain.py save --step 收尾`。

## git（如被授权）

每步提交到功能分支 `feature/<topic>`（不得为 main/dev）；双链辩论＋悬空链接为 0
后合入 dev；整体审查通过再 dev→main 并推送；推送前须用户确认（见
[git工作流约束](../../resistance/git工作流约束/git工作流约束.md)）。

## 退出

以上完成即标记「完成」，收口返回调度方（SMS 主流程继续整合后续 dispatch）。

## 禁止

- 以本技能完成为由结束整段任务；
- 把 `test-results/`、缓存、虚拟环境留在 skill 目录。
