# 用例设计

## 输入

[测试策略/](../测试策略/测试策略.md) 的分层与判据映射。

## 步骤

1. **等价类与边界**：每输入域取代表值＋边界值＋非法值；
2. **状态与流程**：非法迁移、并发/重入、幂等与回滚路径；
3. **失败路径**：超时、依赖不可用、数据缺失——故障注入用例显式列出；
4. **可追溯**：用例编号绑需求/缺陷号，一条用例只断言一个契约点
   （硬约束见 [用例溯源](../../resistance/用例溯源/用例溯源.md)）；
5. **数据**：夹具与种子数据可重建，禁止依赖生产数据快照。

## 用例卡最小字段

| 字段 | 说明 |
|---|---|
| id | 用例号（含所属层，如 U-/I-/E2E-） |
| trace | 验收标准或缺陷单编号 |
| given/when/then | 前置、动作、断言 |
| data | 夹具或种子来源 |
| expect | 失败时的判定方式（不靠人眼） |

## 禁止

- 断言写成「无异常即通过」；
- 一条用例串多个不相关断言（失败不可归因）；
- 用例与被测实现私有细节耦合（重构即大面积变红）。

## 退出

用例集评审通过（每条可执行、可归因），`process_chain.py save --step 用例设计`，
进 [自动化执行/](../自动化执行/自动化执行.md)。
