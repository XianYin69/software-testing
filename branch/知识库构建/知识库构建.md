# 知识库构建

## 目的

把本轮测试经验沉淀成可复用资产，供下次直接取用（拓扑到不能再扩展为止）。

## 应存

- 各栈测试模式与反模式（含 flaky 成因清单）；
- 用例模板与夹具样例（落 `references/`，与代码同层解耦）；
- 缺陷判例：现象 → 根因 → 复现最小用例；
- 引用来源：框架/规范原始链接，同步登记 `dependence/deps.json`
  （每条必附 `source_url`，见 [dependence.md](../../dependence/dependence.md)）。

## 步骤

1. **搜**：内链 `chain recall` ＋ 外网检索定位一手来源；
2. **验**：来源须能解释本轮真实观测（不采信无出处的「经验之谈」）；
3. **落**：写成 ≤50 行文档，文件名即主题；
4. **接**：在 [流程/](../流程/流程.md) 或对应步骤里挂可达链接；
5. **拓扑检查**：确认无新领域可加（加不动为止），否则回步骤 1。

## 判据

- 悬空链接为 0：`python ../../scripts/check_links.py`；
- 行数红线：`python ../../scripts/check_len.py`；
- 每条知识可回答「下次哪个步骤会用到它」。

## 禁止

- 把测试数据、账号、生产快照写进知识库；
- 缓存与运行产物落入 skill 目录（用户缓存目录或不落）。
