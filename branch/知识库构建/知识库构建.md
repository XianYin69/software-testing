# 知识库构建

## 目的

把本轮测试经验沉淀成可复用资产，供下次直接取用（拓扑到不能再扩展为止）。

## 应存

- 编排判例：现象 → 判据 → 动作，绑真实运行记录＋提交号
  （[编排判例/](../../references/编排判例/编排判例.md)）；
- 用例模板与夹具样例（[用例模板/](../../references/用例模板/用例模板.md)，与代码同层解耦）；
- 缺陷判例：现象 → 根因 → 复现最小用例；
- 一手文献摘录：框架/规范原始链接落 [上游文献/](../../references/上游文献/上游文献.md)，
  同步登记 `dependence/deps.json`（每条必附 `source_url`，见
  [dependence.md](../../dependence/dependence.md)）。

## 步骤

1. **搜**：内链 `chain recall` ＋ 外网检索定位一手来源；
2. **验**：来源须能解释本轮真实观测（不采信无出处的「经验之谈」）；
3. **落**：写成 ≤50 行文档，文件名即主题；**规则与条目同轮落地**——只写规则不落条目
   判本步未完成（[ST-002](../../references/编排判例/ST-002-有规则无条目.md)）；
4. **接**：在 [流程/](../流程/流程.md) 或对应步骤里挂可达链接，并更新
   [references.md](../../references/references.md) 的条目现状表；
5. **拓扑检查**：确认无新领域可加（加不动为止），否则回步骤 1。

## 判据

- 悬空链接为 0：`python ../../scripts/check_links.py --root ../..`；
- 行数红线：`python ../../scripts/check_len.py --root ../..`；
- 依赖 lint：`python ../../scripts/lint_deps.py --root ../..`；
- 每条知识可回答「下次哪个步骤会用到它」，且入口可达（不可达＝未接线）。

## 禁止

- 把测试数据、账号、生产快照写进知识库；
- 缓存与运行产物落入 skill 目录（用户缓存目录或不落）。
