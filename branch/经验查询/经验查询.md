# 经验查询

## 目的

在定策略前，先取该领域已有测试经验与判例，避免凭习惯铺测或漏测。

## 步骤

1. **本链检索**：`chain recall`（SMS 链）＋ 本技能 `references/` 既有素材；
2. **外网检索**：框架官方最佳实践、已知缺陷模式、flaky 案例；
   取到的文献落 `references/`，链接写原始出处（见
   [dependence.md](../../dependence/dependence.md)）；
3. **同类技能对照**：语言专项（python-expert / cpp-expert /
   general-programming）与 webapp-testing 的既有约束，取不冲突部分；
4. **结论入链**：`logic_chain.py add --from 经验 --to 策略输入 --why <要点>`。

## 判据

- 每条采纳经验须能落到某一步（策略/用例/门禁），否则不入库；
- 未查证前不得断言「该框架无法测」「覆盖率足够」。

## 退出

经验清单与引用来源齐备，`process_chain.py save --step 经验查询`，
进 [测试策略/](../测试策略/测试策略.md)。
