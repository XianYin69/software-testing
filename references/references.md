# references（素材库）

存**可复用素材与判例**，一条一文件、≤50 行、文件名即主题；不存数据与运行产物。

## 应存

- 编排判例：现象 → 判据 → 动作（[编排判例/](编排判例/编排判例.md)）；
- 用例模板与夹具样例（不含生产数据）（[用例模板/](用例模板/用例模板.md)）；
- 框架/规范的一手文献摘录（必附原始出处，同步登记
  [dependence/deps.json](../dependence/deps.json)）（[上游文献/](上游文献/上游文献.md)）。

## 禁止

- 账号、令牌、生产数据快照、真实用户数据入库；
- 复制其他技能的正文（引用＝链接＋一句话摘要，见
  [委托边界](../resistance/委托边界/委托边界.md)）；
- 无证据条目当定论——一律 status=draft、confidence ≤0.3；
- 只写规则不落条目（有规范无实例，见 [ST-002](编排判例/ST-002-有规则无条目.md)）。

## 取用口径

调用校验脚本一律带 `--root`（见 [ST-001](编排判例/ST-001-校验脚本参数面漂移.md)）。
