# Python unittest：断言与用例组织（摘录）

- 出处：https://docs.python.org/3/library/unittest.html ｜ 访问：2026-10-07
- 版本：Python 3.x 标准库（随解释器版本，无独立许可）｜ 零第三方依赖

## 摘录要点

1. `TestCase` 方法名以 `test` 开头才被收集；`setUp/tearDown` 每例一次；
2. `setUpClass/tearDownClass` 每类一次——重量前置放这里，别放 `setUp`；
3. 断言带 `msg` 参数：失败信息必须含实际值与期望值；
4. `subTest()` 在循环里生成子例，单条失败不终止整轮。

## 选型判据（本技能口径）

| 情形 | 选 | 理由 |
|---|---|---|
| 项目已装 pytest／需参数化与夹具 | pytest | 收集器与夹具更强 |
| 禁第三方依赖（嵌入式／最小镜像） | unittest | 标准库零安装 |
| 只需一次性脚本级自检 | unittest | 无配置成本 |

写实现派语言专家（[委托边界](../../resistance/委托边界/委托边界.md)），本卡只定选型判据。
