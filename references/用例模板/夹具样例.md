# 夹具样例

夹具＝用例的可重建前置。只放**合成数据**与建废逻辑，禁止生产数据、账号、令牌。
口径出处见 [上游文献/pytest-夹具与参数化.md](../上游文献/pytest-夹具与参数化.md)。

## 分层夹具（作用域即成本）

```python
import pytest, json, pathlib

FIXTURES = pathlib.Path(__file__).parent / "fixtures"

@pytest.fixture(scope="session")
def cases():                      # 只读数据，整轮共用
    return json.loads((FIXTURES / "cases.json").read_text("utf-8"))

@pytest.fixture
def db(tmp_path):                 # 函数级，每例独占，跑完自动弃
    conn = make_conn(tmp_path / "t.sqlite3")
    conn.executescript(SCHEMA)    # 自建自毁，禁连真实库
    yield conn
    conn.close()

@pytest.fixture
def client(db, cases):            # 组合夹具
    return App(db, default=cases["baseline"])
```

## 判据

- 夹具内不写断言、不藏副作用（改全局状态＝脆弱用例源头）；
- `yield` 后必须可重入：连续两跑结果一致才算夹具合格；
- 抖动归因先查夹具作用域，见 [失败分诊](../../branch/失败分诊/失败分诊.md)。

## 禁止

- 用 `scope="session"` 复用有写状态的对象；
- 夹具读环境上的既有文件（改由 `tmp_path` 现造）。
