# 用例模板

一条用例一文件（或表内一行），≤50 行，字段齐备方可入 [自动化执行](../../branch/自动化执行/自动化执行.md)。
字段权威定义见 [用例设计](../../branch/用例设计/用例设计.md)，溯源约束见
[用例溯源](../../resistance/用例溯源/用例溯源.md)。

## 空模（复制即用）

```md
id: U-001
trace: AC-3 / BUG-118        # 验收标准或缺陷号，二者必居其一
given: 已登录且配额未用尽
when:  提交 1 条合法请求
then:  HTTP 200 且 body.id 非空
data:  fixture=client, parametrize=cases.json
expect: AssertionError 带实际值与期望值（禁「异常通过」）
risk:  高 ｜ 分层: unit ｜ 预计耗时: 0.5s
```

## 编号口径

| 前缀 | 层次 | 说明 |
|---|---|---|
| `U-` | 单元 | 纯函数／边界值，无外部依赖 |
| `I-` | 集成 | 跨模块，含数据库/文件系统 |
| `E2E-` | 端到端 | Web 端到端派 [webapp-testing]，此处只留挂点 |
| `N-` | 非功能 | 超时／并发／降级 |

## 必须

- `trace` 非空——无 trace 即孤儿用例，不入库；
- `expect` 写成可判定表达式，不写「正常」「无异常」；
- 数据一律夹具化，禁止生产数据快照（[夹具样例](夹具样例.md)）。

## 禁止

- 一条用例断言多目标（失败不可归因）；
- 断言耦合被测实现细节（重构即误红）；
- 用放宽断言／调大超时把失败「修绿」。
