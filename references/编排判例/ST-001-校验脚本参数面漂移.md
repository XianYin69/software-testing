# ST-001 校验脚本参数面漂移

- 状态：confirmed ｜ 置信度：0.9 ｜ 记录日期：2026-10-07
- 来源证据：`check_links.py`／`check_len.py`／`lint_deps.py`／`deps_check.py`
  以位置参数调用实测 rc≠0 的 usage 原文；技能提交 `584cfdc`；任务表
  `task-20261007-214530-023` t1 摸底记录。

## 现象

按 [scripts.md](../../scripts/scripts.md) 的「用法约定」以位置参数跑门禁，
`python scripts/check_links.py .` 一律报 `unrecognized arguments: .`，
usage 显示四件脚本的参数面是 `--root <skill目录>`（`deps_check.py` 另接
`--home`）。同理 [self_update.py](../../scripts/self_update.py) 只认
`--tmp/--target`，不加 `--yes` 只预览。

## 判据

文档写的调用式与脚本真实参数面不一致＝**文档漂移**，属整体审查第 1 项
（流程闭环）缺陷；判据以实际 usage 输出为准，不以口头约定为准
（见 [测试门禁](../../resistance/测试门禁/测试门禁.md)：门禁只认真实运行记录）。

## 动作

1. 文档与判例内一律写 `python scripts/check_links.py --root <skill目录>`；
2. 门禁四件按序全跑并留原始输出：`check_links` → `check_len` →
   `lint_deps` → `deps_check`；
3. 参数面缺陷回该脚本自身修，不放宽脚本判定（见
   [用例溯源](../../resistance/用例溯源/用例溯源.md) 只加严不放宽）；
4. 本条结论 append 进 SMS 链，供 [经验查询](../../branch/经验查询/经验查询.md) 命中。
