# 上下文压缩机制

## 条件

跨步骤流转、或需要引用前序长结论时。

## 必须

- 每步只向下一步传**结论摘要＋产物路径**，不传全文；
- 长文本先压缩再入链（`context_compress.py`），原文留 tmp 或 references 卡片；
- 引用他技能内容＝链接＋一句话摘要（配合
  [委托边界](../委托边界/委托边界.md) 的伞形不重复条款）。

## 禁止

- 把子技能返回的整段正文复述进本体文档或对话收口；
- 用长上下文代替结构化卡片（问题/判据/动作）。

## 违反后果

token 浪费、关键信息淹没、后续步骤定位困难；跨技能内容冗余随上游更新失效。
