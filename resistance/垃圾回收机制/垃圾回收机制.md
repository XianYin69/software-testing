# 垃圾回收机制

## 条件

任何在 `tmp/` 产生的镜像、草稿、下载与中间产物。

## 必须

- 变更先落 tmp 镜像，再 `self_update.py compare` → `release` → `clean`；
- 释放目标＝本技能目录；释放后删除 tmp（`garbage_collect.py --path <tmp>`，默认预览）；
- 沙盒场景：交付并复制到用户指定目标后才删除沙盒（见
  [沙盒机制](../沙盒机制/沙盒机制.md)）。

## 禁止

- 把缓存、日志、运行态文件写进 skill 目录（须落用户缓存目录）；
- 未经 compare 直接 release（静默写盘）；
- 让 tmp 长期驻留（本技能目录内不得出现 `tmp/` 内容）。

## 违反后果

技能目录膨胀污染分发、缓存与版本混淆、隐私泄漏；清理不可追溯。
