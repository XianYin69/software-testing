# 过程链存取

## 条件

步骤进入/退出、审查失败中断、跨会话接续。

## 必须

- 每步完成：`python ../../scripts/process_chain.py save --step <步名> --data <摘要>`；
- 审查失败：`process_chain.py interrupt --step <步名> --reason <原因>`，修复后 `resume`；
- 中断后回原节点继续，不得跳过该步；收口时以「完成/完成项目修改」标记；
- 状态文件落用户缓存目录，不写进 skill 目录。

## 禁止

- 静默跳步（无 save 即视为未做）；
- 失败后不记 interrupt 直接重试；
- 任一路径完成就结束整段对话——完成＝收口返回调度方整合续排。

## 违反后果

流程状态与真实进度脱节，中断不可恢复，派发方无法续排后续任务。
